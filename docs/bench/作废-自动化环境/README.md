# 作废：自动化（Playwright/CDP）环境下的测量

这些结果在自动化浏览器中测得。百度地图会检测自动化环境（`navigator.webdriver`、无头 UA、CDP 连接），
随后瓦片解码 Worker 不再返回、反爬脚本持续高负载：**不加任何图层的空地图也只有 0.5–3 FPS**，
而同一页面在普通 Chrome 中为 60.2 FPS（见 `../real-chrome/`）。

因此这里的帧率、加载时间、主线程占用均不能代表真实表现，仅保留作为排查过程的记录。
其中 GPU 计时（EXT_disjoint_timer_query）只统计本项目图层的绘制，量级可供参考，但正式报告以真实浏览器复测为准。
